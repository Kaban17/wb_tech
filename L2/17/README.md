# Простой Telnet-клиент на Go

Это простая реализация telnet-клиента, написанная на языке Go. Утилита позволяет подключаться к любому TCP-серверу, отправлять данные из стандартного ввода (STDIN) и выводить получаемые данные в стандартный вывод (STDOUT).

## Возможности

- Подключение к TCP-серверу по указанному хосту и порту.
- Настраиваемый таймаут для установки соединения.
- Конкурентный (одновременный) ввод и вывод благодаря использованию горутин.
- Корректное завершение работы при разрыве соединения сервером.
- Завершение работы по нажатию `Ctrl+D` (сигнал EOF) или `Ctrl+C`.

## Сборка

Для сборки проекта убедитесь, что у вас установлен Go (версия 1.18+).

```sh
go build -o mytelnet ./cmd/app/main.go
```
В корневой директории проекта появится исполняемый файл `mytelnet`.

## Использование

Для запуска клиента используйте следующие флаги:

- `--host`: Хост для подключения (по умолчанию: `localhost`).
- `--port`: Порт для подключения (по умолчанию: `8080`).
- `--timeout`: Таймаут на подключение (например, `5s`, `1m`). По умолчанию: `10s`.

### Примеры

1.  **Подключение к локальному тестовому серверу:**

    ```sh
    ./mytelnet --host localhost --port 8080
    ```

2.  **Подключение к публичному echo-серверу с таймаутом 5 секунд:**

    ```sh
    ./mytelnet --host tcpbin.com --port 4242 --timeout 5s
    ```

3.  **Проверка SMTP-сервера (например, Google):**

    ```sh
    ./mytelnet --host smtp.gmail.com --port 25
    ```

Для завершения сессии нажмите `Ctrl+D` или `Ctrl+C`.

## Структура проекта

- `cmd/app/main.go`: Точка входа в приложение, парсинг флагов.
- `internal/telnet/connect.go`: Основная логика telnet-клиента (установка соединения, ввод/вывод).
- `pkg/types.go`: Определения общих типов (например, `Config`).
- `go.mod`: Файл зависимостей Go.
- `test_server/main.go`: Простой TCP-сервер для локального тестирования клиента.
